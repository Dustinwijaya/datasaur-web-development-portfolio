## Website integration

Place the entire extracted folder in a static hosting directory and link to its index.html. Keep relative asset paths intact. Edit index.html for copy and portfolio.css for presentation. The demo uses native details/summary and CSS logo motion. No build step is required.

For an existing portfolio, copy the case-study content and screenshots into that site's component structure, or host this folder as a dedicated project page. The files are a portable implementation, not a Webflow Designer project backup; native Designer editing remains in Webflow.
